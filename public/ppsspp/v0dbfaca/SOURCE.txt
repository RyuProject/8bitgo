8BitGo applies vendor/ppsspp/patches/0001-range-streaming.patch before building.
That patch replaces browser HTTP disc access with strict HTTP Range reads and a bounded block cache.
The unmodified upstream source plus this patch are sufficient to reproduce the distributed WASM files.
